# Personal Portfolio Website (Week 1 - HTML)

## 📌 Project Overview
This project is a basic personal portfolio website created using HTML5.
The goal is to understand HTML structure, semantic elements, forms, and navigation.

## 🎯 Objectives
- Learn HTML structure
- Use semantic tags
- Create internal navigation
- Build a contact form
- Add images with alt text

## 🛠 Technologies Used
- HTML5
- VS Code
- Web Browser (Chrome)

## 📂 Project Structure
week-1-portfolio/
│── index.html
│── README.md
│── images/
    └── profile.jpg

## 🧠 HTML Concepts Learned
- Document structure (DOCTYPE, html, head, body)
- Headings and paragraphs
- Links and images
- Lists (ul, ol)
- Forms (input, textarea, button)
- Semantic tags (header, nav, section, main, footer)
- Attributes (id, class, href, src, required)

## 🧪 Testing
- Opened in Chrome browser
- Checked internal navigation links
- Tested form validation
- Validated HTML structure
